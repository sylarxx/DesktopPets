# 华力 AI 桌面助手 1.0.53

本包供管理员平台或 SYSTEM 静默推送。最终用户无需安装、执行命令或清理文件。

## 本版改进

- 提醒先完成卡片布局再显示；首次显示失败最多补救两次，总时限 10 秒。停止后保留消息，不误标已读。
- 保留原有 30 分钟桌面提醒有效期；补入、重连和队列更新不延长有效期。桌面消失不等于后台已读或任务完成。
- 输入有文字或正在使用输入法时，普通外点和失焦保留输入框；Esc 主动收起并保留草稿。单行自动展开为多行，发送按钮与文字、滚动条分开。
- 完整网络请求与工作台交接设有等待上限，未知结果保留内容，不自动重复提交。
- 长提醒、长任务和错误信息可滚动读完，按钮保留在可见区域；会议蓝色、待办绿色按业务类型统一判断。
- 卡片成功显示后招手两轮；重复消息不重播，拖动优先。旧账号的消息和任务操作结果不会修改新账号状态。

## 保留与交付边界

保留现有登录回调、单击输入、双击工作台、拖动、贴边悬停恢复、右键隐藏/退出、管理员部署方式，以及原版机器人生产图集。

已确认的新机器人外观尚未完成全部生产动作。本版未采用试制图集，以避免动作比例、轮廓和材质跳变。本版也不以关闭 GPU 或全局降低渲染质量处理兼容问题。

CI Windows 的构建、原生窗口及部署验证结果随包附在 `QA-EVIDENCE`；具体场景和环境以报告为准。这些结果不能替代白块原问题机及公司实际 Win10/Win11 客户端验证。原问题机的白块根因尚未确认，本版不宣称该问题已经根治。管理员应先在问题机及少量正常客户端验证，再扩大推送。

## 管理员静默推送

直接 MSI 命令（仅管理员平台/SYSTEM 使用）：

```text
msiexec.exe /i "Huali-AI-Desktop-Assistant_1.0.53_intranet_x64-enterprise.msi" /qn /norestart REBOOT=ReallySuppress
```

也可沿用包内 `Install-HualiAI.ps1` 和 `README.txt` 的管理员部署方式。本包为内网未签名包，签名实际状态见 `SIGNATURES.txt`，沿用企业对未签名内网包的准入策略。

从 1.0.52 升级沿用原有机器级安装、开机启动、协议和用户数据位置。出现未覆盖的问题时停止扩大推送并保留当前用户数据；MSI 不支持直接用低版本覆盖恢复。恢复需基于已验证版本代码构建版本号递增的管理员修复包，不要求最终用户卸载或清理。

MSI 校验值见 `SHA256.txt`。ZIP 含 MSI、部署/卸载脚本、说明、签名信息及验证证据。此包未改动网页端代码。
