# 华力 AI 桌面助手 1.0.55

本版修复 1.0.54 中“机器人招手但卡片没有出现”及“提示未能标记已读、卡片无法收起”的两个已复现缺陷。安装包供管理员平台或 SYSTEM 静默推送，最终用户无需执行安装或清理命令。

## 修复内容

- 通知先完成布局，再在原生窗口显示后等待两次渲染帧并核对窗口可见性；当前显示批次收到确认后才触发招手。窗口隐藏或重建时立即撤销可见状态，迟到的确认不能恢复旧卡片的招手。
- 未收到显示确认时保留三次、十秒的恢复上限；本轮失败释放队首，保留仍有效的未读消息。重复恢复事件不会重置正在进行的重试预算。
- 已读接口返回 `false` 时，有界查询当前账号的已读列表。只有确认同一消息 ID 已读才收起，避免浏览器已读或上次请求实际成功后桌面反复报错。查询没有确认时保留真实失败状态。
- 卡片新增独立关闭按钮，请求中或同步失败也能收起。关闭只控制桌面展示，不更改后台已读；按账号和消息 ID 记录，并在消息有效期内避免重启后立即重弹。旧请求不会覆盖下一张卡片。
- 登录失效、权限不足、超时和已读未确认分别提示，避免全部误报为网络问题。
- 增加主 UI 探针停滞记录，帮助区分宿主线程与卡片渲染器无响应；该记录不代表宿主死锁已经修复。

沿用三十分钟提醒有效期、原生 WebView2 恢复机制、草稿与队列保存、主动隐藏意图及单击/双击/拖动操作。本版没有修改或部署网页端、后端。

## 验证与现场边界

包内 `QA-EVIDENCE` 保存本次 Windows/MSVC 构建、从 1.0.54 静默升级、默认启动、协议回调、真实鼠标/HWND 交互、透明窗口穿透、卸载清理及故障恢复结果；同时保存执行实际应用处理函数的已读冲突、关闭重启和延迟请求复现记录。

Windows 故障测试覆盖模拟会话锁定/恢复、渲染器无响应及退出、浏览器进程退出、首次重建失败、草稿及隐藏状态保留。模拟会话不能代替原问题电脑的定时锁屏验收，截图也无法证明现场那一次的全部触发链。

管理员在原问题电脑上部署后，仍须确认锁屏期间的新提醒在解锁后与招手一致，单击/双击/拖动及草稿正常；确认浏览器先已读后桌面可收起，以及请求失败时关闭并重启不会立即重弹。如仍复发，保留 `%LOCALAPPDATA%\com.huali.ai.mascot\logs\runtime-health.jsonl` 及 `.1` 和故障时间，以便定位实际窗口或进程状态。

## 管理员部署

```text
msiexec.exe /i "Huali-AI-Desktop-Assistant_1.0.55_intranet_x64-enterprise.msi" /qn /norestart REBOOT=ReallySuppress
```

沿用固定 UpgradeCode 和原安装、自启动、协议、用户数据位置。ZIP 包含 MSI、管理员部署/卸载脚本、校验值、说明及验收证据。沿用此前内网未签名包交付方式，实际签名状态见 `SIGNATURES.txt`；企业分发由管理员按现有准入策略执行。
