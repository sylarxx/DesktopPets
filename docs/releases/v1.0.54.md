# 华力 AI 桌面助手 1.0.54

本版修复锁屏后提醒恢复不足、不可见消息阻止单击，以及界面进程异常后必须退出重开的恢复缺口。安装包供管理员平台或 SYSTEM 静默推送，最终用户无需执行安装或清理命令。

## 修复内容

- 卡片本轮显示失败后保留未读消息，解除对单击和后续消息的占用；新的恢复轮次可重新投递仍有效的消息。
- 原生程序接收锁屏、解锁、电源恢复和会话切换。锁屏期间暂停展示重试，解锁后清理过期提醒、重新确认窗口状态并恢复两个消息通道。
- 原生监测界面事件响应，结合 WebView2 进程故障通知执行恢复。无响应时先重载受影响界面，仍失败再重建；浏览器进程退出时直接重建。恢复次数有上限，持续恢复正常后才重新开放预算。
- 恢复时保留输入草稿、按账号隔离的待处理消息和任务、原有效期及主动隐藏意图。结果未确认的操作不会自动重发，恢复不自动标记已读或完成任务。
- 新增独立的运行健康记录，只记录会话和恢复事件、进程号、运行时间等限定字段。文件有大小上限并轮转，不记录登录凭据、回调地址或消息正文。

保留 30 分钟桌面提醒有效期。已过期的夜间消息不补弹；消息在桌面消失不代表后台已读或任务完成。保留原有单击输入、双击工作台、拖动、右键菜单和机器人图集。

## 验证范围

包内 `QA-EVIDENCE` 保存本次 Windows/MSVC 构建、从 1.0.53 升级、默认启动、协议回调、鼠标/窗口、卸载和故障恢复结果。原生故障测试包括模拟会话锁定/恢复、实际阻塞机器人 JavaScript、终止该测试进程所属的 WebView2 渲染进程和浏览器进程；检查主程序仍为同一进程、界面恢复、草稿保留和真实鼠标事件。

模拟会话状态不等于公司 Windows 10/11 原问题机实际过夜。包内报告明确区分这些证据。原问题机仍应在实际锁屏过夜后验收新有效消息、单击、双击及拖动；无法用 CI 代替该项现场验收。本版未把 GPU/驱动故障或整个宿主线程死锁认定为已证实的首发原因。

## 管理员部署

```text
msiexec.exe /i "Huali-AI-Desktop-Assistant_1.0.54_intranet_x64-enterprise.msi" /qn /norestart REBOOT=ReallySuppress
```

沿用包内 `Install-HualiAI.ps1`、`README.txt` 及企业对未签名内网包的准入策略，实际签名状态见 `SIGNATURES.txt`。从 1.0.53 升级沿用原安装、自启动、协议及用户数据位置。ZIP 包含 MSI、管理员脚本、校验值、说明和验收证据。本版未改动网页端。
